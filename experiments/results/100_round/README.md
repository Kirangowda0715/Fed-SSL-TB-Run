# 100-Round Experiment

This folder archives the final outputs of the 100-round Stage 1 + K=20 Stage 2 experiment.

Archive structure:
- logs/ — final training log
- metrics/ — Stage 2 evaluation result
- checkpoints/ — final checkpoint selected for reproducibility

The 100-round experiment is a continuation from the 50-round global checkpoint (round 49). The checkpoint used for continuation is kept in the Kaggle runtime, not committed to GitHub.
